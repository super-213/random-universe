# 随机宇宙发生器

一个运行在浏览器中的交互式宇宙生成与演化模拟器。每次创世都会得到一组新的物理参数、一座新的星系，以及一段从炽热大爆炸延伸至条件结局的独特历史。

![随机宇宙发生器的创世界面](readme-photo/001.png)

## 项目简介

随机宇宙发生器以一个 `XXXX-XXXX-XXXX-XXXX` 格式的 16 位字母数字种子为起点，生成光速、引力强度、精细结构常数、暗能量占比等宇宙参数，并由这些参数继续推导元素稳定性、恒星数量、生命概率、星系形态与远未来时间尺度。

进入宇宙后，可以沿时间轴观察早期高温等离子体冷却、第一代恒星和星系形成、文明扩张与天体远未来。暗能量与真空状态会让后期时间线分流到渐近热寂、大撕裂、大坍缩或真空衰变。整个过程由 Three.js 实时渲染，并支持播放、倍速和任意时间点回看。

## 主要特性

- **种子化创世**：同一个种子驱动宇宙参数、星系结构、文明特征和宇宙事件，保证模拟结果内部一致且可复现。
- **23 项宇宙参数**：展示基本常数、宇宙组成、暗能量状态方程、真空稳定性、生命与远未来结局。
- **5 类星系形态**：棒旋、絮状螺旋、环状、椭圆和不规则星系使用不同的空间分布规则生成。
- **完整宇宙时间轴**：从 `T+0.001 秒` 到 `10^100 年` 量级之后，以对数时间映射覆盖八个演化纪元。
- **条件宇宙结局**：动态暗能量与亚稳真空可把时间线分流到热寂、大撕裂、大坍缩或真空衰变。
- **实时天体事件**：包含超新星、脉冲星、伽马射线暴、类星体活动、磁星耀斑与黑洞合并等事件，并在时间轴上标记其影响。
- **文明演化模拟**：多个文明拥有独立的扩张、合作、侵略与韧性参数，会争夺疆域、形成友好阵营、遭受天体灾变，或以极低概率转化为高维生命。
- **自由探索**：可旋转和缩放星系，在恒星时代点击恒星样本，查看光谱型、温度、行星数量与候选生命信号。
- **无障碍与响应式适配**：支持移动端布局，并尊重系统的“减少动态效果”设置。

## 仿真模拟器如何工作

### 1. 从种子生成宇宙

每次点击“生成新宇宙”都会通过 Web Crypto 创建一个新的 16 位字母数字种子，并按四位一组展示。项目将完整种子映射到 128 位伪随机状态，让后续所有随机过程都由该种子派生，而不是在各模块中直接调用 `Math.random()`。

基础参数并非完全独立的装饰数字。例如：

- 精细结构常数与质子/电子质量比共同影响化学稳定性和稳定元素数量；
- 引力、原初密度涨落与膨胀率共同决定结构形成效率和恒星规模；
- 化学稳定性与微波背景温度进一步影响生命出现概率；
- 暗能量密度与膨胀率会改变恒星形成结束的时间尺度。
- `w₀` / `wₐ` 状态方程会通过离散膨胀步进生成未来尺度因子历史；反转势能是显式的假说分支。
- 亚稳真空以种子化 Monte Carlo 寿命生成一次真空泡成核事件。

这些关系是为了让生成结果具有因果连贯性的启发式模型，并不是对另一套物理定律的严格求解。

### 2. 生成星系与天体

模拟器根据种子选择一种星系形态，并用约 17,000 个恒星粒子构造主体。不同形态使用不同的采样方法：螺旋臂使用半径与角度耦合，环状星系强调主环与碎环，椭圆星系采用三轴分布，不规则星系则由星团与潮汐尾组合而成。恒星随后在软化的星系势与中央致密天体势中作确定性差速运动；同一星系共享主角动量方向，椭圆与不规则星系只改变轨道面的倾角，不会随机反向。有中央巨型黑洞的宇宙会表现出更快的内区轨道，而外区仍主要由整个星系的质量分布束缚。

星系还会根据形态和概率获得中央巨型黑洞、活动星系核、恒星残骸与远未来黑洞族群。恒星拥有各自的熄灭阈值，因此不会在时间轴上同时消失。

双黑洞事件依次表现旋近、合并与阻尼振铃。附近恒星会在带软化项的重心引力场中发生近掠偏转和偏心轨道变化，只有跨入捕获半径的少量星体会逐渐落入合并后的黑洞。合并时还会发出带四极结构的传播波前，并以横向潮汐位移扰动波前附近的恒星采样点；这层形变是为科普可读性做的视觉放大。残余黑洞会按种子化反冲方向偏移并持续留在时间线上。只有富气体环境会额外显示暖色余辉，稀薄或真空环境不会生成超新星式火球。

### 3. 压缩一部宇宙史

时间轴的 `0–1000` 是可视化坐标，而非线性年份。它通过分段对数映射覆盖极端时间跨度：

| 纪元 | 模拟内容 |
| --- | --- |
| 炽热大爆炸 | 高温高密度状态、快速膨胀与冲击波视觉效果 |
| 等离子体时代 | 宇宙冷却，光子仍被自由电子频繁散射 |
| 宇宙黑暗时代 | 复合之后宇宙透明，但恒星尚未点亮 |
| 宇宙黎明 | 第一代恒星与星系形成，再电离开始 |
| 恒星时代 | 恒星、重元素、宜居环境与文明持续演化 |
| 简并时代 · 假说 | 恒星残骸长期绕核运行、逸散或落入黑洞 |
| 黑洞时代 · 假说 | 黑洞通过霍金辐射逐步蒸发 |
| 暗时代 · 渐近 | 辐射继续红移、稀释，可用能量梯度趋近于零 |

对于有限时间结局，当今以后的时间段会根据推演寿命重新做对数映射：幽灵暗能量对应大撕裂，反转势能对应大坍缩，而先于它们发生的真空跃迁会覆盖原有结局。

在 `1×` 速度下完整旅程约 35 分钟；`10×` 约 3 分 30 秒；`100×` 约 21 秒。早期宇宙和热寂前夕会被刻意放慢，以便观察关键视觉变化。

### 4. 文明演化模型

文明模拟在一个由 720 个宜居节点组成的空间图上运行。每个节点连接附近的 6 个邻居，文明从彼此分离的母星起步，并按离散时间步预计算状态快照。

每个文明都有四项行为特征：

- **扩张率**决定探索和殖民前沿的频率；
- **合作倾向**提高接触后建立友好关系的概率；
- **侵略性**推动边界摩擦、敌对和领土争夺；
- **韧性**影响殖民地实力恢复及灾变后的存续能力。

文明相遇后，关系分数会随接触和双方性格变化，并在中立、友好与冲突之间转换。友好文明能够互相增强，敌对文明会比较进攻、守备与随机扰动来决定边界归属。强友好关系会在界面中被组织为阵营。每个种群节点都绑定到一颗确定的宿主恒星，因此会继承中央黑洞引力、双黑洞近场偏转和宇宙结局造成的位置变化，而不是固定在屏幕空间中。

超新星、伽马射线暴、类星体活动等事件会按距离、方向和影响范围削弱恒星系统与文明疆域；恒星能源枯竭后，普通物质文明也会逐渐衰亡。每个种群另有 1% 的概率走向“高维转化”，这是项目的科幻设定层。

### 5. 科学边界

本项目是一件以现代宇宙学时间线为骨架的交互式科普与生成艺术作品，不是科研级 N 体、流体或生物演化模拟：

- 大爆炸被表现为整个可观测区域的高温高密度与空间膨胀，而不是从空间中某个中心向外爆炸；
- 远未来纪元依赖质子衰变、霍金辐射等长期假说，界面中已标记为“假说”或“渐近”；
- 动态暗能量的远未来外推、标量场负势能和真空衰变寿命都是条件模型，不是观测预言；
- 星系尺度、恒星数量、文明疆域和事件影响经过大幅抽象与压缩，以服务实时交互和视觉叙事；
- 恒星运动采用可由时间轴直接求值的约化引力势，而不是恒星之间两两求力的完整 N 体积分；黑洞近场使用软化重心势与捕获半径，因此轨道趋势可信，但不能用于天体测量；
- 双黑洞合并不是超新星式爆炸：主要可观测信号是引力波、合并后振铃与残余黑洞反冲。界面中的星点形变为便于观察而大幅放大，只有种子判定为富气体环境时才显示短暂电磁余辉；
- 生命、文明外交与高维生命属于启发式或科幻模型，不应视作科学预测。

黑洞合并实现参考：

- [LIGO：GW150914 双黑洞合并观测与旋近—合并—振铃阶段](https://ligo.org/science-summaries/gw150914/)
- [Varma 等：合并残余黑洞的引力波反冲](https://arxiv.org/abs/2201.01302)
- [Farris、Liu 与 Shapiro：富气体盘中的双黑洞合并及电磁辐射](https://arxiv.org/abs/1105.2821)

## 操作指南

| 操作 | 效果 |
| --- | --- |
| 点击“生成新宇宙”或按 `R` | 在创世界面重新生成宇宙 |
| 点击“进入宇宙” | 进入当前种子的星系与时间轴 |
| 拖动 / 滚轮 | 旋转视角 / 缩放星系 |
| 播放按钮 | 播放或暂停宇宙时间 |
| `1×`、`10×`、`100×` | 调整时间流速 |
| 拖动时间轴 | 跳转并回看任意纪元 |
| 点击彩色事件标记 | 跳转到对应宇宙事件 |
| 点击“种群” | 展开文明、阵营和外交关系 |
| 点击恒星 | 在可观测阶段查看恒星样本信息 |
| 按 `Esc` | 收起文明面板，或返回创世界面 |

## 本地运行

需要安装 Node.js 和 npm。

```bash
npm install
npm run dev
```

开发服务器启动后，打开终端显示的本地地址即可。

构建与预览生产版本：

```bash
npm run build
npm run preview
```

## 技术栈

- [Vite](https://vite.dev/)：开发服务器与生产构建
- [Three.js](https://threejs.org/)：WebGL 场景、粒子、材质、相机和轨道控制
- 原生 JavaScript、HTML 与 CSS：领域模型、模拟逻辑和界面

## 项目结构

```text
random-universe/
├── index.html                    # 页面结构与交互控件
├── src/
│   ├── main.js                   # 应用入口、场景编排与交互流程
│   ├── domain/                   # 种子随机、宇宙参数、时间与轨道模型
│   ├── simulation/               # 文明扩张、外交、冲突与灾变快照
│   ├── rendering/                # Three.js 材质、天体和时间轴视觉效果
│   ├── ui/                       # 宇宙数据、时间轴与文明面板
│   ├── assets/                   # 构建时打包的资源
│   └── style.css                 # 响应式视觉与动效
├── public/fonts/                 # 字体许可证
└── readme-photo/                 # README 截图
```
